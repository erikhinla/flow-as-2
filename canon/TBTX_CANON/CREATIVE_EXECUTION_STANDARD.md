## 0. Purpose

Brand compliance is solved.

This standard exists so that every creative agent can judge its own work before a human ever sees it.  
Technical correctness is the minimum. Impact is the requirement.

## 1. Permanent Creative Principles

These rules are non-negotiable for every creative task.

1. **The idea comes first.**  
   Materials, lighting, typography, animation, and rendering exist only to strengthen the idea. They are never the idea.

2. **Compliance is not quality.**  
   Passing the Brand Bible is required. Passing the Brand Bible does not make the work good.

3. **Every asset must answer one question immediately.**  
   “What is this trying to make me think or feel?”  
   If the answer is unclear, the work is incomplete.

4. **Every composition must create curiosity.**  
   The viewer should want to spend another few seconds looking.  
   If everything is immediately understood, tension is missing.

5. **The work must feel built, not generated.**  
   Materials behave like real materials.  
   Light behaves like real light.  
   Mechanical systems feel engineered.  
   Weight and scale feel intentional.

6. **Photorealism is not enough.**  
   Beautiful rendering without a compelling concept remains weak.

7. **Concept and craftsmanship carry equal weight.**  
   Neither can compensate for the absence of the other.

## 2. Two Creative Modes

Agents must detect and respect the mode of the task. The two modes use different success criteria.

### 2.1 Brand System Mode
**Purpose:** Teach. Explain. Document. Clarify.

Typical deliverables:  
Architecture diagrams, system illustrations, documentation graphics, product explainers, website structural graphics, sales material, UI support assets.

**Success measured by:**  
Clarity · Accuracy · Consistency · Legibility

### 2.2 Campaign Mode
**Purpose:** Capture attention. Create emotion. Create curiosity. Be remembered.

Typical deliverables:  
Hero images, advertising, launch campaigns, social content, film, narrative visuals, promotional assets.

**Success measured by:**  
Memorability · Emotion · Storytelling · Craft

A task that mixes both modes without declaring which one is primary is defective.  
When the mode is ambiguous, default to Brand System Mode and request clarification.

---

## 3. Cinematic Standard (Campaign Mode)

Campaign work must feel dimensional and physically constructed.

Required characteristics:
- Clear foreground / midground / background separation
- Atmosphere and light interaction
- Real material behavior (reflections, edge light, surface variation, micro-imperfections)
- Optical credibility (falloff, caustics where appropriate, controlled highlights)
- Intentional camera language and framing
- Weight and scale that feel engineered

Flat graphic-layer compositions are unacceptable in Campaign Mode.

---

## 4. Self-Evaluation Gate (Mandatory)

Before any creative asset is marked ready for human review, the producing agent must score the work against these five categories.  
All five must pass. A single failure returns the work to revision.

| Category | Pass Condition |
|----------|----------------|
| **Concept** | There is a clear, single idea that can be stated in one sentence. |
| **Craft** | The piece looks professionally produced at the quality level expected of high-end commercial work. |
| **Story** | The asset communicates more than pure information. |
| **Emotion / Curiosity** | The work creates tension, curiosity, or a memorable feeling. |
| **Brand** | The work aligns with the current Brand Bible (identity rules). |

Failure in any category = incomplete.  
The agent must revise or escalate. It may not present the work as finished.

---

## 5. Human Review Questions

Human reviewers no longer ask only “Did it follow the Brand Bible?”

They also ask:
- Would someone stop scrolling?
- Would someone remember this tomorrow?
- Would this embarrass us if Apple released a similar piece?
- Would this feel at home at a high-end design or advertising festival?
- Does this create emotion or merely explain something?

These questions are the final Creative Gate.

---

## 6. Agent Behavior Rules

1. Read the Brand Bible for identity constraints.  
2. Read this Creative Execution Standard for quality judgment.  
3. Determine the creative mode (Brand System or Campaign).  
4. Execute.  
5. Run the five-category self-evaluation.  
6. Only after all five categories pass may the work be presented for human review.  
7. Default `publish_allowed` remains false unless explicitly overridden by a human.

Agents may not skip the self-evaluation step.  
Agents may not treat Brand Bible compliance as sufficient evidence of quality.
